# Field coverage: every (night, field) pair by exposure count

Every (night, field) pair in deep-db, ordered by exposure count descending. `n_exposures` is the
raw exposure count for that pair across all bands present (`bands` lists the distinct bands seen);
deep-asteroids' own search granularity is per-(night, field, detector, band), so this is the
exposure count a search over that pair's full detector set would see per detector, before any
per-detector image-coverage filtering (`list_night_run_ids.py`'s `--min-coverage`,
`search.detect.MIN_EXPOSURES=2`).

## Summary

- 349 distinct (night, field) pairs, 8,906 exposures total.
- Median 6 exposures/pair, mean 25.5 -- most pairs are brief (likely calibration/pointing) visits,
  not search-depth sequences.
- **40 pairs have >=90 exposures** -- true long-stare pointings, the DEEP survey's actual search
  depth sequences (see `deeper_search_20190402.md`'s note that night 20190402 had exactly one,
  A0b, among its three fields).
- 88 pairs have >=50 exposures.
- 23 pairs have exactly 1 exposure.

A pair with fewer than ~50 exposures is unlikely to be worth a deeper (lower-threshold) search --
with no long baseline to chain detections across, there's little a finer `dx` or deeper
`--num-results` can recover that the production default search would miss. The deeper-search
exploration in `deeper_search_20190402.md`/`compute_cost.md` focused on A0b (103 exposures)
precisely because it's one of the night's only pairs dense enough to matter.
